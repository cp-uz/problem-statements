# cp.uz problem statements

This repository is the PDF archive used by the [cp.uz](https://cp.uz) olympiad problem catalog.
Each problem has one stable, individually addressable PDF at:

```text
<season>/<event>/<set>/<problem>/statement.pdf
```

`manifest.json` records the source, language, provenance, SHA-256 digest, byte size, and page
count for every document. Official statements are preserved without content changes. When no
official individual PDF exists, cp.uz generates a PDF from its canonical Uzbek statement; those
entries are marked `generated`.

The olympiad organizers and authors retain ownership of official statements. Source URLs are
kept in the manifest for attribution and auditing. This repository does not apply the cp.uz code
license to third-party statement content.
